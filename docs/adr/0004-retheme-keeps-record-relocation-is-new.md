# A Retheme keeps the record; a Relocation is a new one

A Retheme (new name, theming or hardware for the same attraction on the same site and layout, including what fans call a retrack) continues the same record, with the old name added to its Name History, so ride counts treat it as one attraction. A new layout or Category on the old site is a new record, even if it reuses the name. For example, Alton Towers' Nemesis (1994) was retracked, had 89 of its 117 supports replaced, its trains repainted and a new theme added, reopening in 2024 as Nemesis Reborn on the same layout: one record, Name History "Nemesis" 1994-2024. A Relocation (dismantled and rebuilt elsewhere) creates a new record at the new Park, linked to the old one, which is closed. We chose this over a split between physical hardware and its presentation at a Park, which was more precise but harder to edit and explain.
